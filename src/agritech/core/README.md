# core

## Purpose
Shared data model used by every brick: places, observations and
interventions. Every observation carries its provenance.
Also defines the structured output of MCP tools: value, unit, source,
date, uncertainty. No I/O in this package.

## Provides
The data model and output format, to all bricks.
